### Origem do Projeto

Esse foi o meu primeiro projeto de programação.

Eu comecei ele no fim do meu terceiro ano no Ensino Médio Técnico no Senac. Eu fazia parte da comissão técnica da ProEx2024, que é uma feira de trabalhos dos alunos do ensino médio. 

A minha ideia era fazer um mapa "interativo" mostrando o locais de apresentação e os horários de apresentação. Por ser o meu primeiro contato com programação, a maior parte do código é feito por IA. 

Eu não sabia como dar prompts efetivos para descrever o que eu queria fazer, toda a estrutura e as funcionalidades não estão muito boas, algumas estão funcionando e outras não. Tanto que até os nomes dos arquivos não são os melhores.

Esse repositório é mais para mostrar onde e como eu comecei a programar.

Em algum momento eu pretendo acabar e melhorar esse projeto, implementando Vite + React para fazer o frontend e talvez Node.js para as funcionalidades do backend.
